4. DOM Element Properties

The DOM provides various properties that allow you to access and manipulate elements in the document.

Some commonly used DOM element properties include:

  • innerHTML: Gets or sets the HTML + Content of an element.
  • innerText: Gets or sets the visible text content of an element.
  • textContent: Gets or sets the text content of an element, including hidden text.
  • value: Gets or sets the value of form elements (input, textarea, select).
  • style: Provides access to the inline styles of an element.
  • className: Gets or sets the class attribute of an element.
  • id: Gets or sets the id attribute of an element.
  • src: Gets or sets the source URL of an image or media element.
  • href: Gets or sets the URL of a link (anchor) element.

5. Attributes

Attributes are additional information or properties that can be added to HTML elements to provide more context or functionality.

Attributes are specified within the opening tag of an HTML element and consist of a name-value pair.

  • href: Specifies the URL of a link.
  • title: Provides additional information about an element.

6. Node Elements

In the DOM, every element, attribute, and piece of text is represented as a node.

Nodes are the building blocks of the DOM tree structure, and they allow JavaScript to interact with and manipulate the content of a web page.

There are several types of nodes in the DOM, including:

  • Element Nodes: Represent HTML elements (e.g.,
    ,

    , ). They can have attributes and child nodes.

  • Text Nodes: Represent the text content within an element. They do not have attributes or child nodes.
  • Attribute Nodes: Represent the attributes of an element (e.g., id, class, src). They are associated with element nodes.
  • Comment Nodes: Represent comments in the HTML code. They are not displayed on the web page.
